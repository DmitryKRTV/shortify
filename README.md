# Shortify

Shortify — сервис для сокращения ссылок.

Проект позволяет пользователям регистрироваться, авторизоваться, создавать короткие ссылки и отслеживать статистику переходов по ним. Для веб-клиента используется REST API, а gRPC API предоставляет альтернативный программный интерфейс для работы с авторизацией, ссылками и статистикой.

Основная функциональность:

- регистрация и вход пользователей;
- создание коротких ссылок;
- переход по короткой ссылке на оригинальный URL;
- сбор статистики переходов;
- просмотр списка созданных ссылок и количества переходов;
- REST и gRPC интерфейсы поверх общей бизнес-логики.
